# Costo Fondos Artesanales

## Importar y exportar artículos

- **Exportar Datos** descarga un backup en PDF. El diseño visible del PDF se mantiene y el archivo también incluye los datos completos en sus metadatos para poder restaurar componentes, cálculos y fotos.
- **Importar PDF** agrega los artículos de un backup a los que ya están guardados; no reemplaza ni elimina los actuales.
- Los backups PDF creados antes de esta función también se pueden importar. Como no guardaban las fotos como datos recuperables, la importación de esos archivos restaura los campos de texto y deja la foto vacía.
